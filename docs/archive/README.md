# Historical visualizations

These files are retained unchanged as research/presentation evidence. They are
not regenerated, are not production inputs, and do not represent current factors.
Use the package CSVs and docs/methodology.md for current values and methods.

- `colombia_employment_factors_methodology.pptx`: historical presentation; its
  displayed dataset counts and methodological descriptions predate current outputs.
- `Employment_Factors_graphs.xlsx`: older source table, pivot summaries, and charts.
  All four original sheets are preserved, including chart-only content.

The bespoke PowerPoint generator was retired. Current spreadsheet review exports
are produced with `build_employment_factors.py --audit-workbook`.
